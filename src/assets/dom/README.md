# DUM demo assets

These assets are distributed under Creative Commons CC0 and are stored locally so the demo works offline.

- `fps-weapons.png` — “FPS Weapons Overlay” by knekko, OpenGameArt: https://opengameart.org/content/fps-weapons-overlay
- `grell-sheet.png` — “Monster for 3d shooter - Sprite” by Pawel “Nmn” Zarczynski, OpenGameArt: https://opengameart.org/content/monster-for-3d-shooter-sprite

No original DOOM artwork, audio, maps, or code is included.

`angel-dialogue-pixel.webp` is an original AI-assisted pixel-art transformation of the portfolio owner's profile photo, created specifically for the DUM narrative scenes.
