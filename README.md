# Portfolio de Angel Cardenas

Portafolio profesional bilingue construido con React y Vite.

## Desarrollo

```bash
npm install
npm run dev
```

## Validacion

```bash
npm run lint
npm run build
node --test tests/blog.test.mjs
```

## Blog

El blog tiene páginas independientes en `/portfolio-angel-cardenas/blog/`.
Los artículos se escriben en Markdown y el build genera sus rutas para GitHub Pages.

Consulta [cómo añadir artículos y validar las rutas](docs/blog.md) y las
[decisiones de diseño y movimiento](docs/redesign.md).

## Despliegue

El sitio se publica mediante GitHub Actions en:
